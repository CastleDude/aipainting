# 图片格式转换工具 — 设计规格

**日期**: 2026-07-08
**状态**: 待审批

---

## 概述

在图片工具页面新增"格式转换"标签页，支持批量将图片转换为统一的目标格式。纯前端实现，不上传服务器。

## 标签位置

```
裁图 | 压缩 | 格式转换 | 去背景 | 换背景 | 磨皮 | 超分辨率 | 滤镜
```

独立标签页，与压缩工具完全解耦，各自独立的状态和参数。

## 支持的格式

| 格式 | 编码方式 | 内置品质 | 说明 |
|------|---------|---------|------|
| JPEG | `canvas.toBlob("image/jpeg", 0.92)` | 0.92（固定） | 不保留透明 |
| PNG | `canvas.toBlob("image/png")` | 无损 | 保留透明通道 |
| WebP | `canvas.toBlob("image/webp", 0.80)` | 0.80（固定） | 保留透明通道 |
| AVIF | `canvas.toBlob("image/avif", 0.50)` | 0.50（固定） | 新一代格式 |
| ICO | 手写编码器，头部 + 内嵌 PNG | 无损 | 最大 256×256，超过自动缩小 |

- 不支持 BMP / TIFF：浏览器 Canvas 无法编码为这些格式
- 品质均为内置固定值，不暴露给用户

## UI 布局

右侧控制面板（极简，无品质滑块）：

```
目标格式:  [ JPEG | PNG | WebP | AVIF | ICO ]

[全部转换]  /  [重置] [全部下载 (.zip)]
```

左侧上传区与压缩工具一致：拖放/点击选择，最多 15 张，网格缩略图展示。

文件列表显示每张的原名 → 转换后文件名，原体积 → 新体积，及体积变化百分比。

## 交互流程

1. 切换到"格式转换"标签
2. 选择目标格式（默认 JPEG）
3. 上传图片（拖放或选择文件，最多 15 张）
4. 点击"全部转换"
5. 每张图片在 Canvas 上绘制后用目标格式编码
6. ICO 格式：额外封装 ICO 头部 + 嵌入 PNG 数据
7. 完成后可单张下载或全部打包 zip

## 体积变化显示

| 场景 | 缩略图/列表显示 |
|------|---------------|
| 新文件更小 | 绿色 `↓XX%` |
| 新文件更大或相同 | 灰色 `—`（兜底：如果转换后体积 >= 原体积，保留原文件） |

## 文件命名

`原文件名.新扩展名`，例：`photo.png` → `photo.jpg`

## 实现要点

- 复用压缩工具的 UI 骨架（上传区、文件列表、批量下载、重置按钮）
- 压缩和格式转换各自独立的状态（文件列表、处理状态等）
- ICO 编码器：纯手写，不引入第三方依赖
  - 结构：6 字节 ICO 头部 + 16 字节 PNG 条目 + PNG 数据
  - 尺寸：max(原图, 256×256)，保持宽高比
- 无需新 API 路由，纯客户端处理
- 需要添加 i18n 键：新标签名、目标格式选项、描述文案
